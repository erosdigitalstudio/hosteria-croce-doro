# Hosteria Croce d'Oro — proposta dimostrativa
Sito vetrina HTML/CSS/JS vanilla, senza backend, compatibile con GitHub Pages. Proposta di Eros Digital Studio, non commissionata.
- Anteprima: apri `index.html` in Visual Studio Code con Live Server (o in un browser).
- Contenuti: modifica solo `js/content.js` (vedi `docs/CONTENT_GUIDE.md`).
- Il sito è `noindex` finché la pubblicazione non è autorizzata (`index.html`, `robots.txt`).
- Nessun dato inventato: i campi `null` mostrano segnaposto.
