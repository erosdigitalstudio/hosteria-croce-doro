# Passaggio al cliente
**Progetto**: sito vetrina premium, demo non commissionata. **Funzioni**: header con menu mobile, hero, sezioni editoriali, menù configurabile, galleria con lightbox accessibile, contatti, footer.
**Da confermare**: indirizzo, telefono, email, pagina Facebook, orari, menù, foto/video autorizzati, dati legali, privacy policy.
**Pubblicazione**: dopo autorizzazione, rimuovere `noindex`, aggiornare `robots.txt`, canonical e `sitemap.xml` con il dominio reale, poi attivare GitHub Pages.
