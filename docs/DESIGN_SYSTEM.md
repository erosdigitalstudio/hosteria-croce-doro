# Design system
**Palette** (variabili in `css/style.css`): verde `#172C29` (dominante), oro champagne `#C2A36A` (solo linee, interazioni, accenti), avorio `#F3EEE4`, grafite `#30312C` (testi). Niente nero puro né altri colori. Sulle sezioni avorio i dettagli usano una variante scurita dell'oro per garantire il contrasto.
**Font**: Cormorant Garamond (titoli, citazioni), Manrope (navigazione, testi, pulsanti, footer). Scala con `clamp()`.
**Componenti**: `.btn`, `.eyebrow`, `.section--light/--dark`, `.split`, `.ph` (segnaposto foto), `.gallery`, `.lightbox`, `.reveal`.
**Movimento**: transizioni 0.35s, `prefers-reduced-motion` rispettato.
