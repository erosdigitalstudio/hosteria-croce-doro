# Manutenzione
- **Mensile**: verifica collegamenti, telefono, orari, link social.
- **Backup**: il repository Git è il backup; tag a ogni rilascio.
- **Immagini**: converti in WebP/JPEG ottimizzato prima del caricamento.
- **Aggiornamenti**: solo contenuti in `content.js`; controlla la console del browser dopo ogni modifica.
- **Privacy**: se si aggiungono Analytics, mappe incorporate o servizi di terze parti, aggiornare privacy policy e informativa cookie.
